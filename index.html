Qualification interpretation

D4H values are interpreted as: Yes = current; a date = expiry/current-to date; ?, - or blank = not held. A past date is treated as expired. You can change the “expiry warning” period below.

Capability framework configuration

A built-in configuration is derived from the May 2026 NZRT Capability and Competency Framework v4.0, with local team-composition interpretations where configured. You can export it, edit it, then reload it without changing this HTML file.
